# KuruBets AI Analyst — подключение

Вкладка интерфейса и клиентский модуль уже добавлены. Для реального поиска необходимо развернуть Supabase Edge Function и задать секреты. Секретные ключи нельзя вставлять в `index.html`, `app.js` или другие браузерные файлы.

## 1. Необходимые секреты

- `TAVILY_API_KEY` — ключ поискового API Tavily (сбор актуальных веб-страниц).
- `OPENAI_API_KEY` — ключ OpenAI API.
- `OPENAI_MODEL` — необязательно; по умолчанию `gpt-4o-mini`.

В Supabase Dashboard откройте **Edge Functions → Secrets** и добавьте эти значения.

## 2. Развёртывание

Из корня проекта, если Supabase CLI установлен и проект связан:

```bash
supabase login
supabase link --project-ref ruxyomwlpaoqxkybxypb
supabase functions deploy ai-match-analysis
```

Функция использует JWT-проверку (`verify_jwt = true`) и дополнительно проверяет активную сессию пользователя. Для работы необходимо войти в аккаунт KuruBets.

## 3. Как работает

1. Браузер отправляет дисциплину, две команды и необязательные турнир/дату в Edge Function.
2. Сервер выполняет несколько поисковых запросов через Tavily.
3. OpenAI формирует русскоязычный аналитический обзор на основе найденных материалов.
4. В интерфейсе показываются сведения о матче, краткий вывод, статистика, новости, факторы по обеим командам, риски и ссылки на источники.
5. Последние 20 анализов сохраняются локально в браузере.

## 4. Важные ограничения

- Это исследовательский обзор, а не гарантия результата и не рекомендация по ставке.
- Поисковая выдача может быть неполной или содержать устаревшие сведения. Всегда проверяйте дату публикации и первоисточник.
- Сейчас идентификация матча выполняется AI по поисковым материалам. Если между командами есть несколько матчей, уточните турнир или дату в форме.
- История анализов хранится в localStorage конкретного браузера и не синхронизируется между устройствами.
